Paso 3 — Normalización

Los montos se normalizan automáticamente

Las facturas argentinas usan punto para miles y coma para decimales. El código detecta el formato y convierte todo a número limpio antes de guardar.

Como viene de la IA (string)
{
  "Invoice SubTotal": "2.152.495,00",
  "Invoice tax": "452.024,00",
  "Invoice Total": "2.626.043,95",
  "Per IIBB BsAs": "21.524,95",
  "Items": [{
    "Quantity": "12.00",
    "Unit cost": "179.374,58",
    "IVA %": "21"
  }]
}
Después de normalizar (number)
{
  "Invoice SubTotal": 2152495,
  "Invoice tax": 452024,
  "Invoice Total": 2626043.95,
  "Per IIBB BsAs": 21524.95,
  "Items": [{
    "Quantity": 12,
    "Unit cost": 179374.58,
    "IVA %": 21
  }]
}
⚙️
Lógica de detección automática
Si tiene punto Y coma → punto es miles, coma es decimal. Si solo tiene coma → es decimal. Si tiene más de un punto → son miles. Cubre todos los formatos de facturas argentinas.
